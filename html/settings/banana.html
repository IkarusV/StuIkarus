Basic Settings

Native Grok Format
  • For models such as grok-imagine-* that generate through /v1/images/generations.
  • When enabled, conversation presets and reference images are ignored; only { model, prompt, n, response_format } is sent.
  • Editing and video modes are unsupported; they still use the multimodal chat/completions route.
  • Grok currently uses fixed output resolutions, so aspect-ratio settings have no effect.

Prompt Replacement Rules

Banana/Grok-specific replacement settings, independent of other image-generation backends. Format: trigger=mode|replacement. Mode values are compatibility tokens and must remain unchanged.

Replacement Mode Guide
  • Before prefix - Insert content at the start of the prompt.
  • After prefix - Insert content after the fixed prefix.
  • Replace - Replace the trigger directly; leave blank to remove it.
  • Per-character replace - Replace in per-character mode.
  • Before postfix - Insert content before the fixed postfix.
  • After postfix - Insert content after the fixed postfix.
  • End - Insert content at the end of the prompt.
