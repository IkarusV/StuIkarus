Knowledge Base

Trigger Depth 0: Uses only the latest user message for keyword matching.
Depth 1: Uses the latest user message plus the previous AI response (two messages total), and so on.
Higher depths trigger more World Info entries but take slightly longer to process.
When enabled, matching World Info entry content is automatically injected into the AI prompt.
This is completely independent of the selection state in "Send Data".
Skip Always-On Entries: When enabled, the knowledge base retrieves only "Force-Enabled" and keyword-triggered entries, ignoring entries that are only always-on unless they also match a trigger keyword.
