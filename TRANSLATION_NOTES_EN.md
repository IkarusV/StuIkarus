# English Localization Notes

The localization translates user-facing static UI text only. It preserves runtime behavior and persisted configuration compatibility.

## Preserved Content

- Element IDs, classes, `data-*` attributes, URLs, and asset paths.
- `<option value>` fields, including Chinese persisted values used by styles or logic.
- Prompt payloads, negative prompts, workflow JSON, regex syntax, model identifiers, API routes, and technical tokens.
- Template variables including `{{角色启用列表}}`, `{{通用角色启用列表}}`, `{{通用服装启用列表}}`, `{{userpersona}}`, and `{{楼层信息}}`.
- Programmatic replacement constants including `前置前`, `前置后`, `替换`, `替换分角色`, `后置前`, `后置后`, and `最后置`.
- Character test formats and `$...$` delimiters.

## Glossary

- Prompt: `提示词`
- Preset: `预设`
- Configuration Profile: `配置档案`
- World Info: `世界书`
- Knowledge Base: `资料库`
- Persona: `人设`
- Character: `角色`
- Outfit: `服装`
- Image Generation: `生图`
- Image Editing: `修图`
- Regex: `正则`
- Vocabulary: `词库`
- Floating Button: `悬浮球`
